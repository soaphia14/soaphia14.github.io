# soapsite

My personal site: projects, research, and the nontechnical stuff (figure skating, crochet, art).

**Live:** https://soaphia14.github.io

Built with [SvelteKit](https://svelte.dev/docs/kit) (Svelte 5), [Tailwind CSS v4](https://tailwindcss.com), and [mdsvex](https://mdsvex.pngwn.io) for Markdown, prerendered to a static site and hosted on GitHub Pages.
